# U-PetFinder - UAE Lost & Found Pet Platform

Reconnecting lost pets with their families across the UAE.

## 🌟 Features

- **Immersive Landing Page** with COCO 3D agent guide
- **Centralized Lost & Found Board** with advanced filtering
- **Privacy-Protected Image Upload** with EXIF stripping
- **UAE Federal Decree-Law No. 45 of 2021 Compliance**
- **Glassmorphism UI** with warm cream palette
- **PWA Support** for offline access

## 🚀 Quick Start

### Local Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Deploy to Firebase

```bash
firebase login
firebase init hosting
firebase deploy --only hosting
```

## 📱 Pages

1. **Landing** - Hero section, COCO agent, features, company profile
2. **Lost & Found Board** - Browse lost/found pets with filters
3. **Add Listing** - Multi-step form for adding pets with privacy protection

## 🔒 Privacy & Security

- Client-side EXIF stripping
- Firebase security rules
- Privacy-first image handling
